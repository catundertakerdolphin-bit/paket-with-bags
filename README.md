# Пакет с пакетами

Минималистичная 3D-игра Арсения Попова: снимайте разноцветные целлофановые пакеты с веток и складывайте в большой пакет, пока их не унёс ветер.

[Играть в браузере](https://catundertakerdolphin-bit.github.io/paket-with-bags/).

Автор: [Арсений Попов](https://t.me/votposmotrim).

## Как играть

Зажмите пакет мышью или пальцем, перенесите к горловине большого пакета слева внизу и отпустите, когда горловина подсветится. Можно поймать и уже улетающий пакет.

Полоска под пакетом показывает время до отрыва: сначала отпускается одна ручка, затем вторая. Удерживаемый пакет защищён от ветра, но общий таймер продолжает идти. Для следующего дерева нужно собрать не меньше 60% пакетов текущего раунда. Ветер усиливается, пакетов становится больше. Счёт собранных и упущенных пакетов сохраняется между раундами; рекорд хранится только в этом браузере.

- Мышь / палец — схватить, перенести, отпустить.
- Enter / пробел — начать или продолжить.
- R — новая попытка.
- Esc — отпустить пакет / закрыть справку.
- Кнопка ? — правила и пауза. Скрытая вкладка тоже ставит игру на паузу.
- Звук выключен по умолчанию; его можно включить кнопкой внизу.

## Запуск

Нужны Node.js 22.12+ и браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5174/`. Проверки и сборка:

```sh
npm test
npm run build
```

Статическая сборка находится в `dist/`. Относительные адреса ресурсов подходят для корня сайта и подпапки GitHub Pages. Workflow `.github/workflows/pages.yml` проверяет, собирает и публикует ветку `main`. Sites использует существующий идентификатор из `.openai/hosting.json`.

## Физика и производительность

Настоящие объёмные ветки и открытые 3D-оболочки пакетов, фиксированная перспективная камера. Каждый мягкий пакет содержит 61 физическую частицу и 84 треугольника; ручки — отдельные ленты той же оболочки. Ограничения расстояний и изгиба, сопротивление воздуха, порывы, гравитация и контакты с ветками дают лёгкую игровую модель пластика. Это приближение, без дорогой симуляции жидкости, самостолкновений и всех складок плёнки.

Физика работает в Worker, максимум один запрос одновременно; при ошибке Worker восстанавливается полный снимок и расчёт продолжается в основном потоке. Фиксированный шаг и ограничение догоняющих шагов удерживают стоимость под контролем; время раунда остаётся реальным. Максимум 22 активных записи пакетов и 8 видимых пакетов внутри приёмника. Рендер ограничен примерно миллионом пикселей и DPR 1.25, тени 512 px; дорогого преломления и постобработки нет. Процедурные данные не требуют внешних картинок, шрифтов или CDN.

`?debug=1` показывает открытые диагностические данные: время кадра/физики, число мешей и треугольников, положения пакетов. В обычной игре этой панели нет.

Проверены перенос мышью, переход на новое дерево, счёт и компоновка в браузере при ширине 390 px. Результаты на конкретном телефоне зависят от его GPU и браузера; физический телефон при этой проверке не использовался.
